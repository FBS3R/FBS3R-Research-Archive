# FBS3R — формальная проверка ключевых результатов в Lean 4

Lean 4.36.0 + Mathlib `v4.36.0`. Сборка: `lake build FBS3R` (≈ 6 700 модулей Mathlib, без кэша —
около часа на 4 ядрах). Проверка аксиом: `lake env lean scripts/Axioms.lean`.

**Итог проверки ядром Lean:** 17 модулей, 151 объявление `theorem`, из них 98 основных теорем
перечислены в `scripts/Axioms.lean`. **Ни одного `sorry`, `admit`,
`native_decide` или собственной аксиомы**. Каждая теорема зависит только от стандартных
`propext`, `Classical.choice`, `Quot.sound`.

## 2. Что найдено неверным (контрпримеры доказаны в Lean)

1. **Коллатц, Proposition «Refined odd-step»** (2025-09-28): «если `n` не top-third, рост ≤ 2» —
   **ложно**: `n = 11` имеет `{log_φ(√5·11)} ∈ [0, 2/3)`, но `h(34) − h(11) = 9 − 6 = 3`
   (`refined_odd_step_counterexample`). Перебор нечётных `n ≤ 2·10⁶` (`scripts/collatz_topthird_search.py`)
   даёт единственное нарушение `n = 11`, так что асимптотически утверждение правдоподобно, но
   в формулировке статьи требует оговорки «для `n` достаточно больших» и не годится в
   неравенство (eq:drift) для всех `J`.
2. **«Единственность фибоначчиевой стратификации»** (2026-04-15, Thm unique-fib; 2026-04-19, Thm unique):
   гипотезы теоремы **несовместны** — аддитивная замкнутость + `a₁=1` + строгая монотонность
   форсируют `a_n = n`, отношение стремится к 1, а не к `r>1`
   (`no_additively_closed_partition_with_ratio_gt_one`). Сами числа Фибоначчи не замкнуты по
   сложению: `F₂+F₅ = 6` (`fib_not_additively_closed`).
3. **Bell-статья 2026-04-15, Thm «Berry Phase Generates Bell Correlation Function»**: для
   `|Φ⁺⟩=(|00⟩+|11⟩)/√2` утверждается `E(a,b) = −cos θ`. Неверно: `⟨σx⊗σx⟩ = +1`,
   `⟨σy⊗σy⟩ = −1`, `⟨σz⊗σz⟩ = +1` (`bell_Phi_plus`). Формула верна для синглета `Ψ⁻`
   (`singlet_Psi_minus`, все три равны −1). В PRA-версии (2026-04-30) состояние уже правильное.
4. **Yang–Mills на S³ (2026-04-19)**: заявленный нижний порог `3/R²` не встречается ни в спектре
   `curl²` = `(k+2)²/R²` (минимум `4/R²`), ни в спектре Стокса `k(k+4)/R²`, которыми пользуются
   работы Киллинга–Бельтрами того же архива (`no_three_in_curl_or_stokes_spectrum`).
   Это доказанная внутренняя несогласованность; сам спектр векторного лапласиана на S³ в Lean
   не формализован.
5. **Hierarchical Bethe (2026-04-21), формула Бине**: при `F₁=3, F₂=5` формула
   `F_n = (φ^{n+2}−ψ^{n+2})/√5` даёт `F₁ = 2`. Верно: `F_n = Fib(n+3) = (φ^{n+3}−ψ^{n+3})/√5`.

## 3. Что не формализовано и почему

* **Дифференциальная геометрия S³** (что оболочки `E_{k,σ}` — собственные пространства curl с
  `μ = σ(k+2)/R`, что поля Киллинга действуют спинами `j_τ`, проектор Лере, нормы проекторов
  `‖Π_W‖ = √(N/(3V))`, теоремы о полном классе редукций). В Mathlib пока нет ротора/теории
  Ходжа на римановых 3-многообразиях; эти факты входят в модули как (стандартные) гипотезы,
  а Lean проверяет всю алгебру, которая из них выводится.
* **Локальная связность множества Мандельброта** (2025-03-05). Это открытая проблема (MLC).
  Аргумент препринта не является доказательством: (а) из `π₁ = 0` локальная связность не
  следует (гребенчатое пространство стягиваемо, но не локально связно); (б) ключевой шаг
  (стр. 213 исходника) объявляет `U = {V(c) < x_N} ∩ B(c₀, ε)` связным потому, что `U` —
  подмножество связного диска; но подмножество связного множества не обязано быть связным;
  (в) эквипотенциальные области `{V < x}` содержат всё `M` и не дают малых окрестностей.
  Формализовать нечего — утверждение не доказано.
* **Условный сингулярный бранч Навье–Стокса** (2026-09-20) — сама статья условна (пять внешних
  гипотез); не является решением проблемы тысячелетия, и её внешние гипотезы не формализуемы сейчас.
* Космологические, онтологические и эмпирические утверждения (тёмный сектор, DESI, «Wave function
  of the void» и т. п.) — не математические теоремы, проверке в Lean не подлежат.
