## Errata A1–A7

Все семь опровержений проверены ядром Lean 4 в пакете `Lean/FBS3R-Lean` (только аксиомы `propext`, `Classical.choice`, `Quot.sound`; все семь теорем перечислены в `scripts/Axioms.lean` и `APEX/Audit/AXIOM_REPORT.txt`). Исправления, помеченные «не формализовано», — стандартные факты, их Lean не проверял.

### A1. Коллатц, Prop. «Refined odd-step» (2025-09-28, `prop:topthird`)

* **Исходное утверждение.** Пусть `x(n) = log_φ(√5·n)`, `n` «top-third», если `{x(n)} ∈ [2/3, 1)`. «If n is top-third then h(3n+1) − h(n) ≤ 3; otherwise the increase is ≤ 2». На этом построено неравенство (eq:drift) `k_{J+1} − k_J ≤ (2 + I_J) − A_J`.
* **Ошибка.** `n = 11`: `{x(11)} ≈ 0.655 < 2/3`, то есть `n` не top-third, но `h(34) − h(11) = 9 − 6 = 3`. Перебор нечётных `n ≤ 2·10⁶` (`scripts/collatz_topthird_search.py`) находит только это нарушение.
* **Исправление.** Для всех `n` верно `h(3n+1) − h(n) ≤ 3` (`Collatz.odd_step`), точнее `h(3n+1) − h(n) ∈ {2, 3}` (`APEX.Collatz.fibHeight_three_mul_add_one`). Уточнённая граница `≤ 2` верна для `11 < n ≤ 2·10⁶` только численно. Неравенство (eq:drift) для всех `J` нужно заменить на `k_{J+1} − k_J ≤ 3 − A_J` (`Collatz.superstep_drift_int`) или отдельно учесть исключение. Гипотеза Коллатца остаётся открытой (статья её решённой не объявляет).
* **Lean.** `FBS3R.Collatz.refined_odd_step_counterexample`.

### A2. «Uniqueness of the Fibonacci Stratification» (2026-04-15, `thm:unique-fib`; та же теорема единственности в 2026-04-19)

* **Исходное утверждение.** Среди бесщелевых неперекрывающихся разбиений `ℕ∖{0}` на интервалы `[a_n, a_{n+1})` с `a₁ = 1`, `a_n → ∞` и `a_{n+1}/a_n → r > 1` фибоначчиево разбиение (`r = φ`) — единственное, удовлетворяющее (1) аддитивной замкнутости `a_m + a_n = a_k`, (2) минимальной избыточности, (3) `a_{n+1}/a_n → φ`. В доказательстве используется `a₁ = a₂ = 1`, что противоречит строгому возрастанию.
* **Ошибка.** Гипотезы несовместны: аддитивная замкнутость вместе с `a₁ = 1` и строгим возрастанием дают `a_n = n`, и отношение стремится к 1, а не к `r > 1`. Сами числа Фибоначчи не замкнуты по сложению: `F₂ + F₅ = 1 + 5 = 6`. Теорема пуста, и выводы о «единственности стратификации» ни на что не опираются.
* **Исправление.** Разбиения со всеми свойствами не существует. Верно только, что интервалы Фибоначчи разбивают `ℤ≥1` (`FibStrat.fib_partition`), а `F_{n+1}/F_n → φ` по формуле Бине.
* **Lean.** `FBS3R.FibStrat.no_additively_closed_partition_with_ratio_gt_one`, `FBS3R.FibStrat.fib_not_additively_closed`.

### A3. Белл и топология S³ (2026-04-15, Thm «Berry Phase Generates Bell Correlation Function»)

* **Исходное утверждение.** Для `|Φ⁺⟩ = (|00⟩ + |11⟩)/√2`: `E(a,b) = ⟨Φ⁺|(σ·a)⊗(σ·b)|Φ⁺⟩ = −cos θ_ab`.
* **Ошибка.** `⟨σx⊗σx⟩ = +1`, `⟨σy⊗σy⟩ = −1`, `⟨σz⊗σz⟩ = +1`, поэтому `E_{Φ⁺}(a,b) = a_x b_x − a_y b_y + a_z b_z`. Это не функция одного угла и не равно `−a·b`.
* **Исправление.** `E(a,b) = −a·b = −cos θ` верно для синглета `|Ψ⁻⟩ = (|01⟩ − |10⟩)/√2` (все три корреляции равны −1). В PRA-версии (2026-04-30) состояние уже исправлено.
* **Lean.** `FBS3R.Bell.bell_Phi_plus`, `FBS3R.Bell.singlet_Psi_minus`.

### A4. Янг–Миллс на S³ (2026-04-19, аннотация и Cor. «Threshold on S³»)

* **Исходное утверждение.** Нижнее собственное значение поперечного векторного лапласиана на `S³(R)` равно `λ₁^V = 3/R²`, отсюда порог `Δ = √3/R` и при `R = 1/Λ_QCD` значение `Δ = √3·Λ_QCD ≈ 520 МэВ`.
* **Ошибка.** Значения `3/R²` нет ни в спектре `curl² = (k+2)²/R²` (минимум `4/R²`), ни в спектре Стокса `k(k+4)/R²`, которые используют работы Киллинга–Бельтрами того же архива. Lean доказывает, что 3 не имеет вида `(k+2)²` или `k(k+4)` при натуральном `k`. Это доказанная внутренняя несогласованность; спектр векторного лапласиана на S³ в Lean не формализован.
* **Исправление (не формализовано).** `3/R² = ℓ(ℓ+2)/R²` при `ℓ = 1` — первое ненулевое собственное значение *скалярного* лапласиана (продольные, точные моды; формула `−n(n+2)/R²` для гармонических многочленов есть в `APEX.S3.Sphere.sphLapF_of_harmonic`). Для поперечных (ко-точных) 1-форм ходжев лапласиан равен `curl²` и имеет минимум `4/R²`, то есть нижняя частота свободного поперечного поля `2/R`. Это согласуется с работой архива 2026-10-06: моды Максвелла `e^{−i(m+2)τ}`, `m ≥ 0`. Для свободного поля порог равен `2/R`, а при той же идентификации `R = 1/Λ_QCD` — `2Λ_QCD`. Массовая щель Янга–Миллса (Клэй) этим не затрагивается и остаётся открытой.
* **Lean.** `FBS3R.KillingBeltrami.no_three_in_curl_or_stokes_spectrum`.

### A5. MLC (2025-03-05, ключевой шаг, стр. 213 исходника)

* **Исходное утверждение.** «The region {V(c) < x_N} … is a connected (in fact, simply connected) set — a topological disk. Therefore, the intersection U — as a subset of this region — is also connected and contains c₀.»
* **Ошибка.** Подмножество связного множества не обязано быть связным: `{0, 1} ⊆ [0, 1]`. Вне Lean есть ещё две ошибки. Области `{V < x}` содержат всё `M` и малых окрестностей не дают. Из `π₁ = 0` локальная связность не следует (гребёнка стягиваема, но не локально связна).
* **Исправление.** Исправленного утверждения нет: доказательство не восстанавливается, MLC остаётся открытой.
* **Lean.** `FBS3R.Misc.subset_of_connected_not_connected`.

### A6. Иерархические состояния Бете (2026-04-21, Thm «Fibonacci scaling», `eq:binet`)

* **Исходное утверждение.** Для `F₁ = 3`, `F₂ = 5`, `F_{n+1} = F_n + F_{n−1}`: `F_n = (φ^{n+2} − ψ^{n+2})/√5` и `F_n = φ^{n+2}/√5 + O(φ^{−n})`.
* **Ошибка.** При `n = 1` формула даёт `(φ³ − ψ³)/√5 = 2 ≠ 3`.
* **Исправление.** `F_n = Fib(n+3) = (φ^{n+3} − ψ^{n+3})/√5`, асимптотика `φ^{n+3}/√5`. Предел отношения `φ` и оценка нулевых мод (`Checks.zero_mode_multiplicity`) от ошибки не зависят.
* **Lean.** `FBS3R.Checks.paper_binet_wrong`, `FBS3R.Checks.F_binet`.

### A7. Benchmark residual invariants, дополнение (2026-05-11, Cor. «Benchmark spectra», `cor:spectra`)

* **Исходное утверждение.** Для `A_n = A₀e^{−βn}`, `β > 0`: `σ² = (A₀/2π²A³)·e^β(e^β+1)/(e^β−1)³`.
* **Ошибка.** `Σ_{n≥0}(n+1)²e^{−βn} = e^{2β}(e^β+1)/(e^β−1)³`. Значение статьи меньше верного ровно в `e^β` раз и отвечает сдвинутому семейству `A_n = A₀e^{−β(n+1)}`.
* **Исправление.** `σ² = (A₀/2π²A³)·e^{2β}(e^β+1)/(e^β−1)³`. Ошибка есть только в файле `2026_05_11_…_supplement.tex`; в PDF основной статьи этого следствия нет.
* **Lean.** `FBS3R.CosmoBench.exp_family_sum`, `FBS3R.CosmoBench.paper_exp_variance_wrong`.
