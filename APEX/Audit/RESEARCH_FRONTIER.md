## Доказано ядром Lean (реестр `ACCEPTED_THEOREMS.txt`, только стандартные аксиомы)
* PXP: рациональная иерархия для всех m (deg = 3m−2, знак, вычет, точный знаменатель); 4-й, 6-й и **8-й** моменты для всех n;
  доказанный DP по битовым маскам (`MaskDP.M_eq_Mnat`) для любого периода k — вычислительный механизм без степеней матриц.
* Блокада радиуса r: размерности; **второй момент для всех r**; тождества промежутков `D_r S_r + z^r B_r = 1`;
  корень ρ_r (единственный, простой, единственный минимального модуля), асимптотика `a_n ~ B_r(ρ)ρ^{−n}/K_r`, σ₁² = 1 − 1/√5.
* Коллатц: запрет ограниченной поправки (log и высота Цекендорфа), точный прирост высоты.
* Braid 2×2: полная классификация, точная норма дефекта. S³: гармонические многочлены, Фишер, (n+1)².
* Спектральное препятствие для e^{−ax}/x; кумулянты смесей; энергетическая оценка; AKLT-синглетный код; ядро наблюдений на оболочках.

## Ближайшие цели (технически ясный путь)
1. Блокада: 4-й момент для всех r (`Conj4`), затем общий закон (`ConjGeneral`) через перенос `Good/GoodR/GoodT` на r соседей.
2. Гауссов предел: моменты `Tr A^{2m}/(a_n n^m) → (2m)!/m! (ρ^{r+1}/K_r)^m` — из рациональности, вычета и леммы о корне; затем метод моментов.
3. 10-й/12-й моменты PXP через MaskDP (вычислительный бюджет ядра).
4. S³: полярное разложение лапласиана → спектр n(n+2) на сфере; масштабирование R⁻² (Янга–Миллса: геометрическая щель исчезает).
5. Квантовые каналы: TraceNorm/CPTP/диамантовая норма — в этом Mathlib нет нужной инфраструктуры; начать с норм Шаттена через сингулярные числа.
