# Фронт исследований после раунда 1

## Достигнуто (проверено ядром Lean)
* Универсальная рекурсия PXP (APEX-16): для **всех** m доказано
  `(Σ_n Tr A_n^{2m} zⁿ)(1−z−z²)^{m+1} = P_m(z) ∈ ℤ[z]`, `deg P_m ≤ 3m−2`, `P_m ≡ (2m)! z^{2m−1} (mod 1−z−z²)`.
  Граница степени сильнее заявленной в препринте; знаменатель точен.
* Явные формулы 4-го и 6-го моментов препринта — для всех n.
* Независимая пересборка `Lean/FBS3R-Lean` (139 целей) и `Lean/OpenProblems` (19 целей) с нуля.

## Ближайшие проверяемые цели (вероятность успеха высокая)
1. `deg P_m = 3m−2` ровно (нужен счёт старшего коэффициента).
2. PXP с однородным полем μ: знаменатель `(1−z−z²)^{k+1}` (гипотеза, есть численная поддержка).
3. Блокада радиуса r: знаменатель `(1−z−z^{r+1})^{m+1}`.
4. Универсальная теорема для произвольного автомата ограничений ближайших соседей (вопрос раздела XIX).
5. Неоднородные связи `J_j`: формализация теоремы о временном трансфере (th:transfer) и весового флакс-сертификата (th:flux).

не являются решением задачи о массовой щели.
