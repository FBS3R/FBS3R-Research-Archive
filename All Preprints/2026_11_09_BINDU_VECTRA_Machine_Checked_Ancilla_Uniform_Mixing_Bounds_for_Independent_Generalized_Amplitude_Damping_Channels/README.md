# BINDU–VECTRA: Machine-Checked Ancilla-Uniform Mixing Bounds for Independent Generalized Amplitude-Damping Channels

We report the exact source-level Lean 4.19.0 formalization of a uniform Schatten-1 estimate for finite products of independent generalized amplitude-damping channels. The verified statement is quantified over an arbitrary number of sites, positive local pump and decay rates, nonnegative time, any finite-dimensional ancilla, and every complex input matrix. Its coefficient is the explicitly defined envelope min{2, 􏰀k (rk + rk2 )} with rk = exp[−(Gk + Kk )t/2]. The proof removes the formerly conditional site-kernel and hybrid-step assumptions. Eight named target theorems have source-matched user-provided Lean build and axiom evidence; all required declarations depend only on propext, Classical.choice, and Quot.sound. A fresh independent kernel replay is required before an independently certified release can be declared. We do not claim formal verification of an exact diamond norm, its optimal mixing exponent, interacting Lindbladians, or the larger BINDU– VECTRA program.
